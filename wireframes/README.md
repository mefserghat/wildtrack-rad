# WildTrack RAD wireframes

Three low-fidelity SVG frames sized for landscape iPad/desktop presentation. The SVGs can be opened in any browser or imported into Figma.

| Frame | Primary stories | FR coverage |
|---|---|---|
| `ranger-report-form.svg` | Ranger saves a report as a draft; Ranger creates a report from a standard template; Ranger submits only complete and attested reports | FR-01, FR-02, FR-03, FR-06, FR-07, FR-09, FR-10, FR-11, FR-12, FR-18 |
| `supervisor-review-queue.svg` | Supervisor approves or rejects a submitted report; Assigned reviewers receive notifications and an action queue | FR-04, FR-17, FR-30 |
| `partner-report-view.svg` | Supervisor sends each partner an authorized report version; Partner downloads a recipient-marked PDF | FR-05, FR-22, FR-32 |

Stories are listed by title (see `03_jira_backlog.csv`). The supervisor frame marks the overdue threshold as pending customer confirmation, matching the requirements spec.

The partner frame shows a land manager, who is not a receipt-acknowledgment recipient (FR-21 is limited to U.S. Fish & Wildlife, state police, and sheriffs), so the Acknowledge button is intentionally absent.
